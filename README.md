# Portfolio

Open `index.html` in a browser. No build step.

## Files
- index.html: markup and photo placeholders
- css/base.css: variables, reset, typography
- css/layout.css: navigation, sections, grids, slider layout
- css/animations.css: loader, reveals, marquee, hovers, cursor
- js/loader.js: intro loader
- js/cursor.js: custom cursor
- js/slider.js: draggable gallery
- js/main.js: menu, reveals, active nav link, activity previews

## Customising
1. Search index.html for `REPLACE PHOTO HERE` and swap each image in assets/images.
2. Replace every "Your Name" and placeholder text.
3. Change colours and fonts in the `:root` block of css/base.css.
